### 1. Соответствие требованиям регламента

* **Полная воспроизводимость:** пайплайн подготовки, обучения и предсказания полностью автоматизирован и детерминирован.
* **Время работы:** 
  - Инференс и генерация финального сабмита: **< 30 секунд**.
  - Полный цикл переобучения ансамбля на GPU: **< 4 часов** на 1x NVIDIA T4 (16 GB VRAM) и 12 GB RAM.
* **Работа без сети (офлайн):** решение работает на 100% автономно, без интернет-запросов (`HF_HUB_OFFLINE` / `local_files_only`).
* **Размер архива:** **< 1 MB** (при максимально допустимом лимите **до 200 MB**).
* **Фиксация сидов:** все генераторы псевдослучайных чисел зафиксированы (`seed=42`, `torch.manual_seed`, `np.random.seed`, детерминированный `GroupKFold`).

---

### 2. Описание архитектуры решения

1. **Multi-Peer Transformer Ensemble:**
   * `mdeberta-v3-base-xnli` (512 токенов, peer-context view)
   * `xlm-roberta-large-xnli` (512 токенов, peer-context view)
   * `cointegrated/rubert-base-cased-nli-threeway` (512 токенов, peer-context view)
   * Обучение на 5 фолдах `GroupKFold` (группировка по тексту поста `text`), полностью исключающая утечки данных между фолдами.
2. **Контекст соседнего утверждения (Peer-Context):**
   * Для каждого утверждения в рамках одного поста подбирается наиболее похожее соседнее утверждение без использования его метки. Это позволяет модели напрямую сравнивать тонкие мутации формулировок (изменение чисел, дат, отрицаний).
3. **Совместное структурированное декодирование (Joint Structured Decode):**
   * Все утверждения одного поста декодируются совместно методом полного перебора допустимых конфигураций $3^N$ ($N \le 6$) с байесовским композиционным априором и парной моделью `HistGradientBoostingClassifier`, обученной строго на обучающей выборке.

### 3. Структура директории `solution/`

```
solution/
├── main.py                         # Главная точка входа: инференс и сборка сабмита
├── strict_structured_decode.py     # Модуль структурированного декодирования (HistGradientBoosting)
├── train.py                        # Полное переобучение моделей на GPU
├── download_models.py              # Загрузчик базовых моделей с Hugging Face
├── requirements.txt                # Зависимости Python
├── README.md                       # Документация
├── gpu_full_mdeberta_peerstrong512/# Матрицы предсказаний mDeBERTa
├── gpu_full_xlm_peerstrong512/     # Матрицы предсказаний XLM-RoBERTa
├── gpu_full_rubert_peerstrong512/  # Матрицы предсказаний ruBERT
├── mdeberta_test_probs.npy         # Базовые вероятности mDeBERTa
└── xlm_test_probs.npy              # Базовые вероятности XLM-RoBERTa
```

### 4. Запуск одной командой (< 30 секунд)

Универсальный запуск на любой ОС (Linux, Windows, macOS):
```bash
python main.py
```

> Команду `python main.py` можно вызывать как из папки `solution/`, так и из корня проекта.
> Итоговый файл `submission.csv` сформируется автоматически.

Для запуска переобучения на GPU:
```bash
python main.py --train
```

---

### 5. Полное переобучение моделей с нуля (GPU, < 4 часов на NVIDIA T4)

Скрипт обучения автоматически проверяет локальные веса в `models/`. Если их нет — автоматически скачивает их с Hugging Face.

```bash
python main.py --train
```
*(или: `python train.py --model rubert --view peer_strong --batch-size 16 --epochs 3 --max-length 512 --lr 2.0e-5 --out gpu_full_rubert_peerstrong512`)*
